What Voice AI is

Voice AI is a phone agent inside HighLevel. A caller rings your number, the agent answers in a natural voice, and it holds a conversation. It can answer common questions, take the caller's details, book an appointment on your calendar and pass the call to a person.

The strongest use is the call nobody would have answered: after hours, during a job, when the line is busy. A caller who reaches an agent that books them in is worth more than a voicemail.

Before you start

  • The "View & Manage Voice AI Agents" permission in the right sub-account
  • An eligible phone number: LC Phone, Twilio or a Number Pool
  • One clear job for the agent, written in a sentence
  • Approved business information: hours, address, services, prices you're willing to quote
  • A calendar to book into and a number to transfer to

1.Create the agent

Go to AI Agents > Voice AI, open the Agent List and click + Create Agent. You can install a prebuilt agent from the Marketplace, create a custom agent in the full-screen builder, or draw one in the Flow Based Builder. Choose the custom agent for a first build.

Set the name, voice, model, language and time zone. Write the inbound welcome message, and choose who speaks first and how long the agent pauses before speaking.

2.Write the prompt

HighLevel's guidance is to define the agent's role, what it collects, what it may and may not discuss, when each action runs, when to transfer and how calls end. Tell it not to guess. A structure that works:

Prompt outlineYou are the phone assistant for [Business], a [type of business] in [area]. Your job is to find out what the caller needs and book a [type of appointment]. Collect their name, phone number and a one-line description of the job. Answer questions only from the knowledge base. If you don't know, say so and offer to have someone call back. Never quote a final price or give [regulated] advice. Transfer to a team member if the caller is upset, has an emergency, or asks for a person. End by confirming what happens next.

Agent prompts are capped at 15,000 tokens, so put long reference material in the knowledge base, not the prompt.

3.Add a knowledge base

Attach a knowledge base with approved sources and tell the agent when to search it. A Voice AI agent supports one knowledge base, so put everything it needs in one place. Short, direct FAQ entries work best, because the answer will be spoken aloud.

4.Add only the actions it needs

ActionUse it for
Appointment bookingBooking straight onto a calendar during the call
Call transferPassing the caller to a person
Agent transferPassing the caller to another AI agent
Send SMSTexting a booking link or confirmation
Update contact fieldSaving what the caller said to the CRM
Trigger workflowStarting follow-up automation
Custom webhookSending data to another system

Each extra action is another thing the agent might do at the wrong moment. Start with booking, transfer and one SMS. After-call actions run without interrupting the caller.

5.Test in two ways

  • Web Call tests in your browser with no phone number. Transfers don't run here.
  • Phone Call tests the real telephone path, including transfers.

Cover the cases that go wrong in real life:

  • A normal booking request
  • A question the knowledge base answers, and one it doesn't
  • An unclear, rambling request
  • Talking over the agent
  • Long silence
  • "Can I speak to someone?"
  • How the call ends

Review the transcript, recording, summary and action results after each call. Change one setting at a time and test again.

6.Deploy it

In the Deploy tab, assign a phone number or Number Pool. Then make two choices.

  • Call routing: Answer Calls Directly, or Use as Backup. Backup means your team's phones ring first and the agent picks up if nobody does.
  • Working hours: All Hours, or a Custom Schedule. A schedule can run past midnight.

For most businesses the right first setup is Use as Backup or an after-hours schedule. Customers who reach a person when one is available, and a capable agent when one isn't, get the best of both.

Check your number's inbound call flow, forwarding, timeout and voicemail settings too. HighLevel notes these can stop the agent from answering.

7.Review the first week

Listen to real calls. Look for questions it couldn't answer, transfers that should or shouldn't have happened, and bookings with missing details. HighLevel's LevelUp 2026 release added agent health monitoring that proposes prompt fixes for you to review, and draft testing with version rollback in Labs.

Rules and good manners

  • Say it's an AI. Open with something like "You've reached the virtual assistant for…". For outbound speech-to-speech agents, HighLevel requires an AI disclosure and a verbal opt-out to be configured.
  • Outbound calling needs approval and compliance setup first. Automated calls are regulated in many countries, so get advice before calling leads with AI.
  • Call recording laws vary. Some places require telling the caller. Add it to the greeting if you record.
  • Always offer a human. An agent that refuses to transfer loses the customer.
