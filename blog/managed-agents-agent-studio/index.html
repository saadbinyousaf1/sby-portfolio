What a Managed Agent is

A Managed Agent is an AI worker you create by describing a job in ordinary language. You don't draw a flowchart. You write something like "When a new lead fills in the quote form, look them up, summarise what they need, add a note to the contact and create a task for the sales team", and HighLevel drafts an agent that does it.

They live in Agent Studio, which is HighLevel's home for custom AI agents. Until recently they were called Super Agents.

Which tool for which job

You want to…Use
Send the same follow-up steps to every leadA normal workflow. Cheaper and predictable
Reply to customers' messages and book appointmentsConversation AI
Get help doing something yourself, right nowAsk AI
Have AI handle a multi-step task that needs judgement, on a triggerA Managed Agent
Control every branch of an AI process by handA Flow Agent in Agent Studio

The honest rule: if a workflow can do it, use a workflow. Reach for an agent when the task needs reading, deciding or writing that a fixed set of steps can't handle.

What agents can do

  • Start on triggers. Tag changed, form submitted, chat, Facebook lead form, survey submitted, plus schedule, appointment, contact and opportunity events. They can also be started from outside HighLevel by an inbound webhook.
  • Use your knowledge. Ground answers in your documents, pages, tables and crawled web content.
  • Act in the CRM. Update contacts, trigger workflows, and create tasks, notes and appointments, within the permissions that already exist.
  • Make media. Generate and edit images, generate audio and create videos. See the AI video guide.
  • Use a computer. Each agent can get its own isolated environment for browsing and file tasks, with credentials stored in HighLevel Keychain and approval controls for sensitive actions.
  • Delegate. A main agent can hand focused tasks to subagents that work in parallel and report back.
  • Reach other apps. Through connectors and MCP servers.

HighLevel's LevelUp 2026 release also added memory of preferences and learned procedures, waits and scheduled follow-ups, and a beta importer that turns an n8n workflow export into a managed agent.

Build your first agent

  1. In a sub-account, go to AI Agents > Agent Studio > Managed Agents.
  2. Click + Create Agent. Describe the goal, the channels, which knowledge bases to use and which CRM actions are allowed. Or pick a prebuilt use case.
  3. Review the draft. Refine it by chatting: "Don't create a task if the contact already has an open opportunity."
  4. Add the trigger that should start it.
  5. Enable media or computer capabilities under Capabilities only if the job needs them.
  6. Test in the testing panel with realistic examples.
  7. Change the status from Draft to Published.
  8. Watch the Activity tab and Agent Logs for the first few days.

A good first project

Pick something low-risk where a mistake is easy to spot and costs little. A lead summary agent is ideal:

Example instructionWhen the Quote Request form is submitted, read the answers. Write a three-line summary of what the lead wants and how urgent it sounds. Add it as a note on the contact. If the budget answer is over $5,000, add the tag high-value and create a task for the account owner due today. Never message the contact.

It reads, judges and writes, which a plain workflow can't do well, and "never message the contact" keeps a bad run invisible to customers.

Keep it under control

  • Give narrow permissions. Allow only the actions the job needs. An agent that can send messages can send wrong ones.
  • Put a filter on the trigger. An agent that runs on every tag change burns runs fast.
  • Keep people in the loop for anything customer-facing until you've read enough logs to trust it.
  • Read the logs. Agents fail quietly. The Activity tab shows what each run did.
  • Know its limit. The Computer capability currently works in chat and manual runs, not on triggers.

Common questions

What are Managed Agents in HighLevel?

Managed Agents are AI agents you create by describing what you need in plain language, without building a flowchart. They live in Agent Studio and follow a draft, test and publish lifecycle. They were previously called Super Agents.

What is the difference between Managed Agents and Flow Agents?

Managed Agents are built from conversational instructions. Flow Agents are built by hand on a visual canvas of nodes. Both live in Agent Studio.

How are Managed Agents billed?

By runs. AI Employee Growth includes 100 runs a month and Unlimited includes 1,000. On pay-per-use, runs are billed by model and token use. HighLevel provides 30 free test runs a month in the Test section.

Can a Managed Agent act outside HighLevel?

Yes. HighLevel says Managed Agents can reach external apps through connectors and a growing MCP catalogue, and can be triggered by inbound webhooks.
